GWSObject

def GWSObject(
    *args, **kwargs
):

dict subclass that also provides access to keys as attrs, and has a pretty markdown repr

GWSObject recursively wraps Google API responses while retaining concise representations for common resource fields.

files = g2obj({'files':[dict(id='report', name='Quarterly report', owners=[{'displayName':'Alex'}])]}, {})
test_eq(files.files[0].owners[0].displayName, 'Alex')
files.files[0], files.files[0].owners[0].displayName
(GWSObject(id='report', name='Quarterly report', owners=1), 'Alex')

Retry handling

Google returns legacy reasons in error.errors and structured reasons in ErrorInfo entries in error.details. These reasons identify retryable 403 rate-limit errors. Other failures retain the transport’s retry classification.

rate_limited = APIError('Quota exceeded', status_code=403, raw={'error':{'errors':[{'reason':'userRateLimitExceeded'}]}})
forbidden = APIError('Permission denied', status_code=403)
test_eq((_retryable(rate_limited), _retryable(forbidden)), (True, False))
_retryable(rate_limited), _retryable(forbidden)
(True, False)

Retry-After accepts a number of seconds or an HTTP date. This date is 12 seconds after the supplied current time. Invalid values do not supply a delay.

dated_response = httpx2.Response(503, headers={'Retry-After':'Tue, 14 Nov 2023 22:13:32 GMT'})
dated_error = APIError('Service unavailable', status_code=503, response=dated_response)
test_eq(_retry_after(dated_error, now=1700000000), 12)
_retry_after(dated_error, now=1700000000)
12.0

RetryInfo.retryDelay is a duration in seconds, including fractional seconds.

retry_info = APIError('Try again later', status_code=429, raw={'error':{'details':[{
    '@type':'type.googleapis.com/google.rpc.RetryInfo', 'retryDelay':'2.5s'}]}})
test_eq(_retry_info(retry_info), 2.5)
_retry_info(retry_info)
2.5

A quota error can name its accounting window in ErrorInfo.metadata. Here the minute started 30 seconds ago. The retry waits for the remaining 30 seconds plus a one-second margin.

quota = APIError('Quota exceeded', status_code=403, raw={'error':{'details':[{
    '@type':'type.googleapis.com/google.rpc.ErrorInfo', 'reason':'RATE_LIMIT_EXCEEDED',
    'metadata':{'quota_unit':'1/min/{project}/{user}', 'window_start_time':'1700000000'}}]}})
test_eq(_quota_wait(quota, now=1700000030), 31)
_quota_wait(quota, now=1700000030)
31.0

Retry delays use Retry-After, then RetryInfo.retryDelay, then quota-window metadata. If none supplies a valid delay, retries use exponential backoff with jitter. max_wait defaults to 300 seconds and applies to every delay source. Longer delays stop retries without shortening the required wait.

wait = _retry_delay(quota, 0, 1, 64, now=1700000030)
test_eq(wait, 31)
test_is(_retry_delay(quota, 0, 1, 64, max_wait=30, now=1700000030), None)
wait
31.0

Without a timing hint, a retryable error uses exponential backoff. A permission error without a rate-limit reason is not retryable.

unavailable = APIError('Service unavailable', status_code=503)
test_eq((_retryable(unavailable), _retryable(forbidden)), (True, False))
backoff = _retry_delay(unavailable, 2, 1, 64)
assert 4 <= backoff <= 5
backoff
4.694767496006301

An explicit Retry-After takes precedence over backoff. A wait limit rejects a longer delay instead of retrying early.

retry_response = httpx2.Response(503, headers={'Retry-After':'12'})
retry_error = APIError('Service unavailable', status_code=503, response=retry_response)
test_eq(_retry_delay(retry_error, 0, 1, 64), 12)
test_is(_retry_delay(retry_error, 0, 1, 64, max_wait=10), None)
_retry_delay(retry_error, 0, 1, 64)
12.0

_retry_action chooses wait, refresh, or stop without performing the action. Its second result is the delay for wait, otherwise None. The 12-second server delay is rejected when it exceeds max_wait or no attempts remain.

test_eq(_retry_action(retry_error, 0, 3, can_refresh=False), ('wait', 12))
test_eq(_retry_action(retry_error, 0, 3, can_refresh=False, max_wait=10), ('stop', None))
test_eq(_retry_action(retry_error, 2, 3, can_refresh=False), ('stop', None))
_retry_action(retry_error, 0, 3, can_refresh=False)
('wait', 12.0)

A 401 permits a credential refresh only when credentials are available and no refresh has already been attempted. Exhausting the request attempts takes precedence over refreshing.

unauthorized = APIError('Unauthorized', status_code=401)
test_eq(_retry_action(unauthorized, 0, 3, can_refresh=True), ('refresh', None))
test_eq(_retry_action(unauthorized, 1, 3, can_refresh=False), ('stop', None))
test_eq(_retry_action(unauthorized, 2, 3, can_refresh=True), ('stop', None))
_retry_action(unauthorized, 0, 3, can_refresh=True)
('refresh', None)

GWSTransport

def GWSTransport(
    *args, gcls:NoneType=None, creds:NoneType=None, **kwargs
):

Thin async transport over httpx2. By default each request gets a fresh client, so nothing is tied to an event loop; pass client= to use a persistent client that you manage (and close via aclose).

GWSTransport reads the current credential token when constructing request headers. Updating the credentials changes the next request’s authorization header. These example tokens are not sent to Google.

example_creds = Credentials('example-token')
authed_transport = GWSTransport(creds=example_creds)
test_eq(authed_transport._request_headers()['Authorization'], 'Bearer example-token')
example_creds.token = 'replacement-token'
auth_header = authed_transport._request_headers()['Authorization']
test_eq(auth_header, 'Bearer replacement-token')
auth_header
'Bearer replacement-token'

GWSTransport.request

async def request(
    *args, raw:bool=False, n_retries:int=5, # Maximum attempts, including the initial request
    base:float=1.0, # Initial exponential backoff and jitter range, in seconds
    max_backoff:float=64.0, # Maximum exponential component, in seconds
    max_wait:float=300.0, # Maximum individual retry wait, in seconds
    headers:NoneType=None, params:NoneType=None, json:NoneType=None, data:NoneType=None, files:NoneType=None,
    content:NoneType=None
):

Execute a request and decode JSON/text/binary response.

GWSTransport.request performs the selected retry action and preserves the original exception when retries stop. Successful JSON responses become GWSObject values. This request finds Drive in Google’s public API directory without credentials.

directory = await GWSTransport().request('GET', 'https://discovery.googleapis.com/discovery/v1/apis')
drive_entry = first(o for o in directory['items'] if o.name == 'drive' and o.preferred)
test_eq(drive_entry.version, 'v3')
test_is(type(drive_entry), GWSObject)
drive_entry.name, drive_entry.version
('drive', 'v3')

request_bytes

def request_bytes(
    request
):

Serialize a buffered httpx2.Request as HTTP/1.1

request_bytes writes an HTTP/1.1 message from an httpx2.Request. response_from_bytes reads one complete response for that request. HTTP framing is handled by h11. The response retains its headers and decoded body.

request = httpx2.Request('GET', 'https://api.example/things/one')
wire = b'HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\n\r\none\r\ntwo'
response = response_from_bytes(wire, request)
test_eq(response.content, b'one\r\ntwo')
response.status_code, response.content
(200, b'one\r\ntwo')

GWSOpFunc

def GWSOpFunc(
    op_spec, client, base_url, form_encoder:NoneType=None, defaults:NoneType=None

Each batch call supplies the same arguments as an individual GWSOpFunc operation. These two calls become separate HTTP requests inside one MIME body.

batch_spec = OpSpec(group='things', name='get', path='things/{id}', verb='GET', route_params=['id'])
batch_op = GWSOpFunc(batch_spec, GWSTransport(), 'https://api.example/', noop)
batch_content,batch_requests = batch_op._batch_content([dict(id='one'), dict(id='two')], 'requests')
test_eq([r.url.path for r in batch_requests], ['/things/one', '/things/two'])
PrettyString(batch_content.decode())

Multipart responses are decoded back into ordered objects or structured APIError values before retry handling.

A multipart response can contain both a resource and an error. This example uses two GET calls and a response body written in the batch wire format.

batch_body = rb"""--response
Content-Type: application/http

HTTP/1.1 200 OK
Content-Type: application/json

{"id":"one"}
--response
Content-Type: application/http

HTTP/1.1 403 Forbidden
Content-Type: application/json

{"error":{"message":"Quota exceeded","errors":[{"reason":"userRateLimitExceeded"}]}}
--response--
"""
batch_response = httpx2.Response(200, headers={'Content-Type':'multipart/mixed; boundary=response'}, content=batch_body)

Decoded results retain call order. The successful resource remains available while retry handling considers the rate-limit error.

batch_results = batch_op._batch_results(batch_response, batch_requests)
test_eq(batch_results[0].id, 'one')
test_eq((batch_results[1].status_code, batch_results[1].retryable), (403, True))
batch_results[0], batch_results[1].status_code
(GWSObject(id='one'), 403)

Each batch chunk uses _retry_action to decide which failed parts to retry. Successful results stay in place. A chunk refreshes credentials at most once after a 401 and waits for the longest delay required by its remaining parts. Retry options apply to both the batch HTTP request and its failed parts.

GWSOpFunc.batch

async def batch(
    calls, # Dictionaries of operation arguments, in result order
    chunk:int=50, # Calls per batch request, at most 100
    return_exceptions:bool=False, # Return per-call APIError values instead of raising
    n_retries:int=5, # Maximum attempts for each batch request and failed part
    base:float=1.0, # Initial exponential backoff and jitter range, in seconds
    max_backoff:float=64.0, # Maximum exponential component, in seconds
    max_wait:float=300.0, # Maximum individual retry wait, in seconds
):

Run dictionaries of arguments for this operation through Google’s discovery-advertised HTTP batch endpoint, retrying only the failed parts

batch preserves input order, retries only failed parts, and optionally returns structured per-call errors.

Client for one Google API, built from its discovery document, with resources as attribute groups such as gmail.users.messages

GWSOpFunc.pages

def pages(
    *args, **kwargs
):

Yield every page from a Google list operation, passing each nextPageToken on as page_token

Google list operations expose pages, which forwards each nextPageToken until the response has no next page.

gmail = GWSApi('gmail', creds=creds)
pages = gmail.users.messages.list.pages(user_id='me', max_results=1)
page1,page2 = await anext(pages),await anext(pages)
test_ne(page1.messages[0].id, page2.messages[0].id)
page1,page2
10

batch can fetch the messages listed on the two pages above in one request. Results follow the order of calls. With return_exceptions=True, a failed call returns an APIError alongside successful messages instead of raising.

calls = [dict(user_id='me', id=p.messages[0].id, format='metadata') for p in (page1, page2)]
messages = await gmail.users.messages.get.batch(calls, return_exceptions=True)
test_eq(len(messages), len(calls))
messages

After a 401, the transport refreshes the credentials once and retries. The fresh token is saved back to the token file. This authenticated example requires the gmail client and credentials from above.

creds.token = 'not-a-valid-token'
msgs = await gmail.users.messages.list(user_id='me', max_results=1)
test_eq(json.loads(Path(creds.token_path).read_text())['token'], creds.token)
